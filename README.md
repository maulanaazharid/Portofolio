# 🌐 Personal Portfolio Website

Website portofolio pribadi yang dirancang untuk menampilkan latar belakang, keahlian, dan berbagai proyek yang telah saya kerjakan.

![Live Demo](https://img.shields.io/badge/Demo-Vercel-black?style=for-the-badge&logo=vercel)

## 🚀 Live Demo
Lihat website secara langsung di sini: **(https://portofoliomaulanaazhar.vercel.app/)**

---

## 🛠️ Tech Stack
- **HTML5:** Struktur dan konten halaman web.
- **CSS3:** Penataan gaya, tata letak, dan responsivitas tampilan.
- **JavaScript:** Interaktivitas dan fungsi dinamis website.
- **Vercel:** Platform untuk pembagian (deployment) dan hosting web secara langsung.

---

## 📸 Fitur Utama
- **Responsive Design:** Tampilan menyesuaikan dengan baik di perangkat desktop maupun mobile.
- **Project Showcase:** Menampilkan daftar proyek terbaik beserta deskripsi dan tautannya.
- **Contact Info:** Memudahkan pengunjung atau recruiter untuk menghubungi saya.

---
